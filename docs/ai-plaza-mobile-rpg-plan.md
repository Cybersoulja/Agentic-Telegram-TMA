# AI Plaza Mobile RPG

**Project Plan v0.1**
**Space Age Hustle Universe**

---

## Vision

Create a mobile-first text RPG that combines authored storytelling, procedural content, and AI collaboration.

Unlike a traditional AI chatbot RPG, AI Plaza separates responsibilities between dedicated systems:

- **INK** tells the story.
- The **Game Engine** enforces rules.
- **Craft Agents OSS** provides intelligent advisors and procedural generation.
- The **Canon Registry** protects the world's continuity.
- **React Native (Expo Snack)** presents everything through a polished mobile interface.

The result is a game that feels like D&D meets Mass Effect meets AI-assisted interactive fiction while remaining faithful to the Prime Canon of Space Age Hustle.

---

## Design Principles

### 1. Canon First

Nothing generated by AI may contradict Prime Canon.

Everything flows from the Canon Registry.

```
Prime Canon
  ↓
Setting Canon
  ↓
System Canon
  ↓
Story
  ↓
Gameplay
```

### 2. AI Assists

AI never becomes the Game Master.

Instead it acts as specialists.

Players remain the decision makers.

### 3. Decisions Matter

Everything revolves around the Op Xero Decision Loop.

```
Experience
  ↓
Observation
  ↓
Interpretation
  ↓
Decision
  ↓
Consequence
  ↓
Learning
```

Every quest feeds this loop.

## Player Command System

The player can type commands naturally.

```
scan
land
inventory
journal
talk trill
use medkit
equip rifle
travel
repair ship
map
status
help
```

Internally they become engine calls.

```
scanPlanet()
travel.advance()
combat.attack()
inventory.open()
quest.advance()
```

## Long-Term Vision

AI Plaza becomes the interactive front door to the Space Age Hustle universe. It is more than a game — it is a living learning platform where players explore worlds, solve problems alongside AI advisors, and grow through the Op Xero Decision Interface.

The architecture is designed so every future product — whether it's Relay 713, Trill Astro Academy, or even a fantasy setting built on the Magic Matrix — can plug into the same foundation. By keeping Canon, Narrative, Rules, and AI as separate layers, the universe can evolve for years without rewriting the core.

This is the v0.1 Architecture Plan. From here, every feature, issue, and pull request should map back to one of these systems, giving the project a clear roadmap from prototype to full platform.
